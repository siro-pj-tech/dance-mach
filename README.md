# SARUMAN GAMES — DANCE MATCH!

サルマンのダンスに合わせて、シルエットと同じポーズのカードを見つける音楽クイズです。流れる音楽とステージの光を楽しみながら、全12問に挑戦！

## ゲームを遊ぶ

[DANCE MATCH! を遊ぶ](https://siro-pj-tech.github.io/dance-mach/)

スマートフォンの縦画面を基本に、パソコンでも縦型の画面で遊べます。音楽と効果音が流れますので、タイトル画面のスライダーで音量を調整してください。

## 遊び方

1. タイトル画面で曲を選び、「Dancing Time!」を押します。選択した曲は試聴できます。
2. ステージに黒いシルエットと3枚のカードが現れたら、同じポーズのカードを選びます。
3. ランプがすべて消えるまでは、何度でも選び直せます。最後に選んだカードで正誤を判定します。
4. 12問が終わると、スコア・正解率・最大コンボを発表。もう一度同じ曲に挑戦することも、別の曲を選ぶこともできます。

早く正解するほど高いスコアを狙えます。連続正解を続けるとコンボボーナスも加算されます。通常モードの理論最高スコアは22,500点です。

## 楽曲とハイパーモード

最初に遊べるのは、テンポも雰囲気も異なる3曲です。

- **MONKEY GROOVE** — 100 BPM、ファンキーなディスコ
- **SARUMAN FEVER** — 120 BPM、シンセと四つ打ちのダンス
- **BANANA RUSH** — 140 BPM、スピード感のあるエレクトロ

3曲すべてを最後まで遊ぶと、**ハイパーモード**が解禁！ 全問のランプが2個になり、得点は1.5倍になります。さらに「TROPICAL SWING」と「DISCO MOONLIGHT」の2曲も選べるようになります。理論最高スコアは33,750点です。

ハイスコアと解禁状態、音量設定は使用中のブラウザに保存されます。別の端末やブラウザには共有されず、ブラウザのデータを消去すると失われます。
